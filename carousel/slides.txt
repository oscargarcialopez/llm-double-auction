## Slide 2

THE THEOREM

2 / 8

Gemini agents in a sealed-bid double auction · code & data in the first comment

Myerson–Satterthwaite (1983)

A buyer values an item at v; the seller's cost is c.

Each knows only its own number. No trading rule can

be all four at once:

1

Efficient: every deal with v > c happens.

2

Manipulation-proof: it still works when both sides

bid strategically (Bayes–Nash equilibrium).

3

Voluntary: nobody expects to lose by taking part.

4

Self-funded: no money from outside.

With v and c uniform on 0–100 €, a rule that keeps

2–4 realises at most

$\dfrac{\mathrm{gains\ realised}}{\mathrm{gains\ available}}\;\leq\;\dfrac{9/64}{1/6}\;=\;\dfrac{27}{32}$

= 84.4%. The missing 15.6% is the price of private

information, not a modelling failure: no prompt or

model can win it back under these rules.

## Slide 3

THE GAME

3 / 8

Gemini agents in a sealed-bid double auction · code & data in the first comment

Split-the-difference double auction

Buyer bids b, seller asks s, sealed and at the same

time. If b ≥ s they trade at p = (b + s)/2.

Against asks spread evenly above $s_{\min}$, the

buyer's best bid is

$\max_{b}\;\int_{s_{\min}}^{b}\left(v-\dfrac{b+s}{2}\right)\mathrm{d}s\;\;\Rightarrow\;\; b=\dfrac{2v+s_{\min}}{3}$

The seller's problem mirrors it. Solving both

(Chatterjee & Samuelson, 1983):

$b(v)=\dfrac{2}{3}\,v+\dfrac{25}{3}\qquad s(c)=\dfrac{2}{3}\,c+25$

so they trade exactly when

$v-c\;\geq\;25$

Deals with a gap under 25 € never happen. They hold

exactly the 15.6% the theorem says no rule can save,

so this simple auction is the best possible one.

## Slide 4

WHY 27/32

4 / 8

Gemini agents in a sealed-bid double auction · code & data in the first comment

Where the other 15.6% goes

The gap d = v − c of a random pair has a triangular

density. Trading only when d ≥ t realises

$G(t)=\int_t^{100} d\;\dfrac{100-d}{100^2}\;\mathrm{d}d\;=\;\dfrac{(100-t)^2\,(100+2t)}{6\cdot 100^2}$

First best G(0) = 16.67 €, equilibrium

G(25) = 14.06 €:

$\dfrac{G(25)}{G(0)}\;=\;\left(\dfrac{3}{4}\right)^{2}\cdot\dfrac{3}{2}\;=\;\dfrac{27}{32}$

kept: 84.4%

lost: 15.6%

## Slide 8

IF YOU BUILD AGENTS THAT TRADE

8 / 8

Four tests before you ship

1

Benchmark against the frontier, not 100%. Here it

is 84.4%: an agent pair above it is not in

equilibrium, so one side could do better by bidding

differently, and a smarter rival will.

2

Change the rules to tell recall from reasoning.

Famous games get recited: Flash named

Chatterjee–Samuelson every time, so the test that

counted was the k = 1/3 variant, which it also

solved.

3

Test the framing you will ship. Flash-Lite fell

from 44.9% to 16.8% as a shopping assistant; Flash

stayed at 84.2%.

4

Measure exploitability with held-out best

responses, and block dominated moves: the cheap

seller asked below its own cost 60 of 200 times

where a trade could happen.
