# Fonts

Vendored so the figures and the carousel render the same on any machine.

- `IBMPlexSans-{Regular,Medium,SemiBold}.ttf`: IBM Plex Sans 3.005, unmodified, from
  [IBM/plex](https://github.com/IBM/plex), under the SIL Open Font License 1.1
  (`OFL-IBMPlexSans.txt`). Reserved Font Name "Plex".
- `STIX2Text-{Regular,Italic,Bold,BoldItalic}.otf` and `STIX2Math.otf`: STIX Two 2.02, unmodified,
  from [stipub/stixfonts](https://github.com/stipub/stixfonts) (`archive/STIXv2.0.2/OTF`), under the
  SIL Open Font License 1.1 (`OFL-STIXTwo.txt`). Used by the carousel.
